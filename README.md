To use our program, follow these steps:

1. Download FinalProjectf.zip file.
2. Extract the file.
3. Open an IDE (VS Code, Pycharm, etc).
4. Drag the "main" python source code from the extracted file into the IDE that you are using. 
5. Click run. 

To use the matrix/shell sort data structures, simply copy paste the code into any IDE, then hit run.
